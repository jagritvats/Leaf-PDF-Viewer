# Bundled OCR data

`eng.traineddata` is the English model from [tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast),
used unmodified. Copyright the Tesseract OCR contributors, licensed under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

More languages are downloaded only when you ask for them ("Add languages…" in the OCR dialog).
